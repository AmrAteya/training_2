# Coffee Shop Landing Page

An early learning project from 2020.

A one-page landing site for a fictional coffee shop, built with HTML, CSS and jQuery. All text is placeholder copy.

## What it does

- A full-height header with a scroll-down arrow that animates to the features section.
- A work gallery with a "Show more" button that fades in extra items.
- A testimonial slider whose arrows hide on the first and last slide.
- Smooth page scrolling through the jQuery NiceScroll plugin.

## Run it

Open `index.html` in any browser. There is no build step.

## Credits

Uses [jQuery](https://jquery.com), [jQuery NiceScroll](https://github.com/inuyaksa/jquery.nicescroll), [Font Awesome 4](https://fontawesome.com/v4/) and [normalize.css](https://necolas.github.io/normalize.css/).
